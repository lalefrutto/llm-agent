# CAPABILITIES.md — что агент умеет и чего не умеет

## Умеет

- Отвечать на вопросы, используя короткую и долгосрочную память
  (см. `memory/`).
- Искать информацию через инструмент веб-поиска (см.
  `agent/tools/web_search.py`).
- Читать/писать файлы в рамках рабочей директории песочницы
  (`agent/tools/file_ops.py`).
- Выполнять код Python в изолированном контейнере
  (`agent/tools/code_exec.py`).
- Делегировать подзадачи специализированным под-агентам
  (Researcher, Executor, Critic/Verifier — см. `agent/nodes/`).
- Применять навыки (skills) из каталога `skills/` для повторяемых
  типов задач.

## Не умеет / намеренно не делает

- Не выполняет код вне песочницы и не обращается к сети из песочницы
  напрямую (сеть у sandbox-контейнера отключена, см.
  `docker/docker-compose.yml`).
- Не хранит секреты/учётные данные в памяти.
- Не принимает решения с необратимыми последствиями (удаление,
  финансовые операции) без явного подтверждения пользователя — see
  `prompts/system_prompt.md`, раздел "Guardrails".
- Не заменяет верификацию человеком в задачах с высокой ценой ошибки.

## Ограничения используемых LLM

Локальные модели 7–9B параметров уступают топовым проприетарным
моделям в сложных многошаговых рассуждениях и в редких/длиннохвостых
фактах. Это компенсируется: (а) tool-calling вместо парametric-знаний
там, где это возможно, (б) шагом self-critique (под-агент Critic),
(в) evals, отслеживающими деградацию качества (см. `evals/`).
