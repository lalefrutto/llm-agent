# Code Review (self-check) Skill

## Обязательная проверка перед `code_exec`

1. **Сетевые вызовы** — код не должен содержать `requests`, `socket`,
   `urllib`, `subprocess` с сетевыми утилитами. В sandbox сеть
   отключена на уровне контейнера, но эту проверку агент делает
   заранее, чтобы не тратить попытку впустую и не маскировать
   реальную причину сбоя.
2. **Файловая система** — пути должны быть относительными и внутри
   `/workspace`. Отклонять `../`, абсолютные пути вне `/workspace`,
   обращения к `/etc`, `~/.ssh` и т.п.
3. **Ресурсоёмкость** — нет ли неограниченных циклов/рекурсии; если
   есть работа с большими данными — добавить явный лимит
   (`timeout_s`, ограничение на размер входа).
4. **Переменные окружения** — код не должен читать `os.environ`
   целиком или пытаться найти в нём секреты.
5. **Идемпотентность записи** — если код пишет файлы, не должен
   безусловно перезаписывать существующие файлы пользователя без
   явного указания в задаче.

## Что делать при обнаружении проблемы
Не выполнять код. Вернуть оркестратору структурированный отказ с
указанием конкретной строки/паттерна, из-за которого код заблокирован
(см. `prompts/subagent_executor.md`).
