# Report Writing Skill

## Порядок действий

1. **Начать с ответа на исходный вопрос**, а не с хронологии того,
   что делал агент — пользователь читает сверху вниз и должен сразу
   увидеть суть.
2. **Структура:** Вывод (1-2 предложения) → Обоснование/данные →
   Ограничения и допущения → (опционально) Рекомендуемые следующие
   шаги.
3. **Не пересказывать внутреннюю маршрутизацию** ("сначала я вызвал
   researcher, затем...") — если пользователь явно не спросил "как
   ты это делал".
4. **Числа — с единицами измерения и периодом**, не голые цифры.
5. **Если часть задачи не выполнена** (достигнут MAX_STEPS, инструмент
   недоступен) — сказать это прямо в отчёте, а не замалчивать.

## Частые грабли
- Отчёт-простыня без визуальной иерархии (заголовки/списки).
- Смешение фактов, полученных из источников, и собственных выводов
  агента без разделения.
- Дублирование одной и той же цифры в разных формулировках.
