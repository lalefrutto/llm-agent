# Web Research Skill

## Порядок действий

1. **Декомпозировать вопрос** на 2-4 под-вопроса перед поиском —
   один широкий запрос вместо этого даёт поверхностные результаты по
   каждому под-вопросу.
2. **Минимум 2 независимых источника** на каждое фактическое
   утверждение, которое войдёт в финальный ответ с уверенностью
   "high confidence".
3. **Отдавать приоритет первоисточникам** (официальная документация,
   репозиторий, пресс-релиз) над агрегаторами и форумами.
4. **Явно фиксировать дату информации** — особенно для быстро
   меняющихся тем (цены, версии ПО, рейтинги моделей).
5. **При противоречии источников** — не выбирать произвольно:
   сообщить оба варианта и указать, какой источник более авторитетен
   и почему.

## Частые грабли
- SEO-оптимизированные статьи-агрегаторы выдают себя за первоисточник.
- Даты публикации статьи ≠ дата актуальности описываемого факта.
- Понижение уверенности не значит "не отвечать" — confidence: medium
  с оговоркой лучше отказа от ответа.

## Формат вывода
Findings → Sources (со ссылками) → Confidence → Open questions
(что осталось непроверенным).
